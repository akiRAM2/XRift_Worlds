# KALEIDOME

暗いドームの中に立つと、足元から揺らぎをもった細い光の線の波紋が広がり、その波紋が天井ドームに万華鏡の文様として映ります。波紋の線からはオーラのような光の糸が不規則に立ち上っては消え、空間には流れ場に乗った煙のような光の糸が漂います。

## 設計

| 要素 | 実装 |
| --- | --- |
| 波紋 | 各アバター（自分は getLocalMovement、他人は useUsers の getMovement）が7秒ごとに、**その時点の立ち位置を中心**に波紋を放つ。中心は発生位置に固定。輪郭は角度方向の正弦波の重ね合わせでうねり、広がるほど揺らぎが大きくなる。さらに半径に比例した楕円のゆがみ（つぶれ具合と向きは波紋ごとに違い、ゆっくり変化）を持つ。主線＋内側2本の細い線＋淡いにじみ。時間の進み方は4分の1（`RIPPLE_TIME_SCALE` = 0.25）で、実際の寿命は56秒、同時最大48個。ドームの中の人数が多いほど線を細くする（1人で1倍、2人で0.8倍、4人で約0.57倍、8人で約0.36倍。数秒かけてなめらかに変化） |
| 天井ドーム | 実物の2ミラー方式の万華鏡を再現。30°で合わせた2枚の鏡を天頂から覗く形で、12個の像が黒い背景に円い曼荼羅として並ぶ（ドームは半径28mで床の縁にぴったり乗り、万華鏡は地平線＝床の縁まで途切れずに続く）。正面の扇にはオブジェクトセルがそのまま見え、残りは鏡像で、1回ごとに左右反転し、反射回数に応じて暗く（反射率0.9）わずかにぼやける。セルには色ガラスの破片とガラスの粉が入り、筒全体とセルがそれぞれゆっくり回る。セルを裏から照らす光がプレイヤーの波紋で、波紋が通った所だけガラスが透けて色づく |
| 床 | 暗い床に霧、淡い万華鏡の等高線、瞬く微光。波紋の実像と、ほのかな万華鏡の映り込み |
| オーラの糸 | 波紋1つあたり84本の細いリボン（全体で1ドローコールのインスタンシング）。根元は波紋の輪の上に乗り、個体ごとにずれた時間窓で伸びて、揺れて、浮き上がりながらほどけて消える。遠くでも1.3px以上の幅を保つ |
| 花びらの群れ | 6つの群れ×420枚（インスタンシング1ドローコール）。群れごとにドームの中を回る閉じた道筋があり、花びらは先頭から最大26秒遅れてその道筋を追うので、曲がると群れ全体がしなる。群れの軸の周りを螺旋状に回り、ふくらみが波のように伝わる。花びらはしずく形で進行方向を向き、1枚ずつひらひらとロールして角度でひかる。状態なし・全員同期 |
| BGM | `public/bgm.m4a`（元の ambient.wav から頭の無音77msを除き、つなぎ目を30msだけ重ねて AAC 128kbps・約2MBにしたもの）。Web Audio の AudioBufferSourceNode で、ループの終点をサンプル数で正確に指定してつなぎ目なく繰り返す。ブラウザの自動再生制限があるので、最初のクリック・タップ・キー操作で4秒かけてフェードインする |
| カラーテーマ | サーバ時計で全員同期。4テーマ（MOONLIT AURORA / ROSE NEBULA / GOLDEN DUSK / DEEP SEA）を120秒ごとに30秒かけて移る |

## スマホ対応の方針

- ドローコールは数個（ドーム・床・外側の地面・境界の輪・流体の糸・きらめく粒・オーラの糸）
- ポストプロセス、影、テクスチャ不使用。模様はすべてプロシージャル
- 重いのは床とドームのフラグメント（波紋24スロットのループ）。数を減らす場合は `RIPPLE_SLOTS`（48）
- 波紋のループは、線・にじみ・揺らぎ・楕円のゆがみが届く範囲（`rippleReach`）の外のピクセルでは計算を飛ばす（省く寄与は0.001未満で見た目は同じ）
- 天井で波紋の中心を鏡の正面の扇へ折り込む計算は、ピクセルごとではなく毎フレームCPUで1回だけ行い `uRippleFold` で渡す
- 花びらの枚数は `SCHOOLS` × `PER_SCHOOL`
- シェーダーへ渡す時刻は2400秒周期で折り返す（float精度対策）。周期運動はすべて 2π/600 または 2π/2400 の整数倍の角速度にそろえてある
- GLSL の `smoothstep` は必ず edge0 < edge1 で書く（逆順は未定義動作で、環境によって0になる）

## 確認用URL

- `?walk` 歩行プレビュー
- `?capture&cam=x,y,z&look=x,y,z` 全景プレビューの視点指定（例: `?capture&cam=0,1.6,0.5&look=0,20,-0.3` で天井を見上げる）

## 実行

```powershell
cd public/Kaleido_Garden
npm ci
npm run dev        # http://127.0.0.1:5176/ （全景プレビュー／歩行プレビュー切替）
npm run typecheck
npm run build      # dist/ に remoteEntry.js を出力
npx @xrift/cli login
npx @xrift/cli upload world
```
