# KALEID DOME

暗いドームの床一面に万華鏡模様が変容し続ける、XRift向けの没入空間です。立つ人の足元から波紋が広がり、床の表示がそのまま天井に万華鏡として映ります。頭上では3,500の光の破片が渦を巻いて漂います。

## 設計

| 要素 | 実装 |
| --- | --- |
| 床 | シェーダー1枚。万華鏡対称に折ったFBMノイズの等高線模様＋極座標グリッド（`gardenPattern`） |
| 波紋 | 各アバター（自分はgetLocalMovement、他人はuseUsersのgetMovement）が10秒ごとに1回、**その時点の立ち位置をスナップショットした中心**から波紋を放つ。中心は発生位置に固定され、歩いても付いてこない。発火管理はJS側（サーバ時計基準）、同時最大16個。広がるほど万華鏡折りノイズと角度の揺らぎで輪郭が崩れる |
| 天井ドーム | 床の表示（`gardenPattern`）を、方位をセクター折り・半径を床半径へ対応づけて映す＝「床を万華鏡で見た像」。ドーム自体の淡い模様と星の瞬きが下地 |
| 光の破片の渦 | GPUインスタンシング1ドローコール。渦の軌道に流れ場ドリフトを重ねて不規則に漂い、進行方向フレームの中で破片ごとにランダムなローカル軸回転をする。計算は頂点シェーダー内で完結 |
| カラーテーマ | サーバ時計で全員同期。パレットが120秒ごとに次のテーマへ24秒かけて遷移、対称数も6.5〜11.5で緩やかに変動 |

## スマホ対応の方針

- ドローコールは数個（床・ドーム・境界リング・破片・外側の地面）
- ポストプロセス、影、テクスチャ不使用。模様はすべてプロシージャル
- FBMは最大4オクテーブ（ワープは3）
- 破片は1枚2三角形×3,500枚。数を変える場合は `src/World.tsx` の `PETAL_COUNT`
- シェーダーへ渡す時刻は600秒周期で折り返す（サーバ時計のepoch秒をそのまま渡すとfloat精度で模様と軌道が崩壊するため。すべての周期運動は600秒の整数周期に揃えてある。波紋の発生時刻も同じ折り返し時計で管理する）

## 実行

```powershell
cd public/Kaleido_Garden
npm ci
npm run dev        # http://127.0.0.1:5176/ （全景プレビュー／歩行プレビュー切替）
npm run typecheck
npm run build      # dist/ に remoteEntry.js を出力
npx @xrift/cli login
npx @xrift/cli upload world
```
