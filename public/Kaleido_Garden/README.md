# 枯山水万華鏡 — KALEIDO GARDEN

枯山水の庭と万華鏡を組み合わせた、XRift向けの没入空間です。円い庭の砂紋は万華鏡の対称で花のように開いては消え、空のドームにも同じ模様が映ります。頭上では3,500枚の花びらがゆっくりと渦を巻いて回遊します。

## 見どころ

| 要素 | 実装 |
| --- | --- |
| 庭の床 | シェーダー1枚。万華鏡対称に折ったFBMノイズの等高線が変容し続ける。石と訪問者の足元から波紋 |
| 空のドーム | 床と同じ模様関数・パレットを共有するシェーダー1枚 |
| 花びらの渦 | GPUインスタンシング1ドローコール。軌道計算は頂点シェーダー内で完結（CPUは時刻uniformのみ） |
| 季節 | サーバ時計で全員同期。パレットが120秒ごとに次の季節へ24秒かけて遷移、対称数も6.5〜11.5で緩やかに変動 |
| 石・縁石 | 位置ハッシュで頂点をずらした低ポリゴン＋固定コライダー |

## スマホ対応の方針

- ドローコールは十数個程度（床・ドーム・石・縁石・花びら・地面）
- ポストプロセス、影、テクスチャ不使用。模様はすべてプロシージャル
- FBMは床・ドームとも最大4オクテーブ（ドームのワープは3）
- 花びらは1枚2三角形×3,500枚。数を変える場合は `src/World.tsx` の `PETAL_COUNT`
- シェーダーへ渡す時刻は600秒周期で折り返す（サーバ時計のepoch秒をそのまま渡すとfloat精度で模様と軌道が崩壊するため。すべての周期運動は600秒の整数周期に揃えてある）

## 実行

```powershell
cd public/Kaleido_Garden
npm ci
npm run dev        # http://127.0.0.1:5176/ （全景プレビュー／歩行プレビュー切替）
npm run typecheck
npm run build      # dist/remoteEntry.js を生成
```

## XRiftへの配置

```powershell
npx @xrift/cli login
npx @xrift/cli upload world
```

ワールド名・説明・サムネイル・物理・カメラ設定は `xrift.json` にあります。
